# Romance Agent Rules (v6, World Calendar canon)

## Before Every Chapter

Ask internally:

1. Who is naturally present?
2. What is the chapter's main objective?
3. Is there room for a romantic beat?
4. Which relationship currently has narrative momentum?
5. Would this beat strengthen the main story?
6. Is the tone appropriate?
7. **If Iris is present, is she a textual adult (~WC21+) in this scene? If not, the beat must be strictly platonic.**

## Automatic Insertion Rules

The agent MAY insert a romantic beat when: characters have downtime; the relationship is currently active; the setting naturally allows it; it does not interrupt a critical scene; all involved characters are adults.

The agent MUST NOT insert one when: a character is dying; a major tragedy is unfolding (The Teacher's death, Elena's sacrifice, the Architect's own death); the chapter is delivering a critical reveal (Builder/Architect lore, Movie 2–3 mysteries); the scene requires concentrated political tension; the emotional tone would be damaged; a character present is not yet an adult.

## Frequency

Normally: 0–2 romantic beats per chapter; fewer during action-heavy chapters; more only in dedicated romance/slice-of-life chapters. Do not force the quota.

## Priority

fan-service vs plot → choose plot.
fan-service vs character development → choose character development.
When both can coexist naturally → combine them.

## Illustration Integration

A fan-service illustration should only be generated if it has character value, comedy value, relationship value, or memorable visual value — and only if every character shown is a textual adult. Never generate images solely because a character is attractive.

## Output Discipline

The agent should never announce: "Now I will add a harem scene."

The scene must feel like part of the story. The reader should experience: character → interaction → emotion → consequence, not: fan-service inserted here.
